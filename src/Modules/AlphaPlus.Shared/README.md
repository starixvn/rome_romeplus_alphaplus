# AlphaPlus.Shared

This project contains shared components, utilities, and common functionality used across the AlphaPlus solution.

## Project Structure

- `Extensions/` - Extension methods and utility functions
- `Models/` - Shared data models and DTOs
- `Constants/` - Shared constants and configuration values
- `Interfaces/` - Common interfaces used across the solution

## Dependencies

- .NET 8.0
- Microsoft.Extensions.Configuration.Abstractions (8.0.0)
